HTML 게임을 앱처럼 만들기

게임 파일을 GitHub에 올리고, 내 아이콘을 누르면 게임이 바로 열리도록 만드는 7단계예요.

1파일 준비하기

컴퓨터에 폴더를 하나 만들고 아래 파일 4개를 넣어요.

파일설명
index.html게임 파일. 이름을 꼭 index.html로 바꿔요
icon-192.png아이콘 그림, 192×192 픽셀
icon-512.png같은 그림, 512×512 픽셀
manifest.json앱 이름과 아이콘 정보 (2단계에서 만들어요)

2manifest.json 만들기

메모장에 아래 내용을 붙여 넣고 manifest.json으로 저장해요. "게임 이름"만 바꾸면 돼요.

{
  "name": "게임 이름",
  "short_name": "게임 이름",
  "start_url": "./index.html",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#ffffff",
  "icons": [
    { "src": "icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}

저장할 때 파일 형식을 '모든 파일'로 바꿔야 manifest.json.txt가 되지 않아요.

3index.html에 아이콘 설정 넣기

index.html을 메모장으로 열고 <head> 바로 아래 줄에 붙여 넣은 뒤 저장해요.

<link rel="manifest" href="manifest.json">
<link rel="icon" href="icon-192.png">
<link rel="apple-touch-icon" href="icon-192.png">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-title" content="게임 이름">
<meta name="viewport" content="width=device-width, initial-scale=1">

마지막 줄은 휴대폰 화면에 맞추는 설정이에요. 원래 파일에 이미 있으면 빼도 돼요.

4GitHub 가입하고 저장소 만들기

  1. github.com에서 회원가입을 해요.
  2. 오른쪽 위 + → New repository를 눌러요.
  3. Repository name에 영어로 이름을 써요 (예: mygame).
  4. Public을 고르고 Create repository를 눌러요.

5파일 올리기

  1. 저장소 화면 하늘색 상자 아래의 uploading an existing file을 눌러요.
  2. 1단계 파일 4개를 한꺼번에 끌어다 놓아요.
  3. 4개가 목록에 다 보이면 맨 아래 초록색 Commit changes를 눌러요.

아래쪽 git 명령어 상자들은 쓰지 않아도 돼요.

6GitHub Pages 켜기

  1. 저장소 위쪽 Settings → 왼쪽 메뉴 Pages를 눌러요.
  2. Branch를 main, 폴더는 /(root)로 두고 Save를 눌러요.
  3. 1~2분 뒤 새로고침하면 주소가 나와요. 예: https://아이디.github.io/mygame/
  4. 주소를 눌러 게임이 잘 열리는지 확인해요.

7아이콘으로 만들기

  • 컴퓨터 크롬: 주소 열기 → 주소창 오른쪽 설치 아이콘(⊕) 또는 점 세 개(⋮) → '페이지를 앱으로 설치'
  • 안드로이드: 크롬으로 주소 열기 → 점 세 개(⋮) → '홈 화면에 추가' 또는 '앱 설치'
  • 아이폰: 사파리로 주소 열기 → 공유 버튼 → '홈 화면에 추가'

내 아이콘이 생기고, 누르면 주소창 없이 게임이 바로 열려요. 학생들에게는 6단계 주소만 보내 주면 돼요.

게임을 고쳤다면 5단계처럼 새 index.html을 다시 올리세요. 1~2분 뒤 반영돼요.
